- Tab: `Data`

- Fitur: pencarian, muat ulang data, dan unduh Excel (.xlsx).

## Mengaktifkan GitHub Pages
1. Buka **Settings → Pages** pada repository ini.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
4. Setelah deployment selesai, halaman tersedia di:
   https://appfathanmubina.github.io/SURVEYFM/

## Izin Google Spreadsheet
Pastikan pengaturan berbagi spreadsheet adalah **Siapa saja yang memiliki link — Pelihat (Viewer)**. Halaman hanya membaca data dan tidak mengubah spreadsheet sumber.
